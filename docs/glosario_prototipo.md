# Glosario del prototipo

Términos usados por `desarrollo.md`, `Mecanicas.md` y la campaña Archivo de ceniza. Las reglas se limitan al subconjunto jugable actual.

| Término | Significado |
|---|---|
| Atributo | Puntuación de Fuerza, Destreza, Constitución, Inteligencia, Sabiduría o Carisma. El modificador es `floor((puntuación - 10) / 2)`. |
| Prueba de característica | d20 más modificador y competencia si aplica; igualar o superar la CD es éxito. |
| Salvación | Prueba para resistir un efecto; usa el atributo indicado por el efecto. |
| Ataque | Tirada contra la Clase de Armadura (CA); un 1 natural falla y un 20 natural impacta críticamente. |
| Ventaja / desventaja | Se tiran dos d20 y se conserva el mayor / menor. Si ambas afectan la misma tirada, se anulan. |
| Iniciativa | Prueba de Destreza que determina el orden de turnos. |
| PV | Puntos de vida actuales y máximos de una criatura o personaje. |
| Condición | Estado temporal que altera acciones o movimiento; en el prototipo se usan Derribado y Agarrado. |
| Casilla táctica | Espacio del tablero isométrico; equivale a 5 pies. El movimiento inicial es de 6 casillas por turno. |
| Región / hexágono | Mapa de viaje y su celda; cada hexágono representa 3 millas de diámetro. |
| Bioma | Tipo de terreno de un hexágono, con nombre, descripción, dificultad y posibilidad de tránsito definidas por datos. |
| Punto de interés (POI) | Lugar destacado de la región con descripción y acciones de acceso o servicio. |
| Encuentro | Situación resuelta en el mapa táctico o por una tabla ponderada de región. |
| Entidad | Personaje, criatura u objeto representado en el tablero y asociado a datos de campaña. |
| NPC / aliado | Personaje no controlado directamente; Mira puede dialogar, unirse al grupo y recibir una orden de ataque. |
| Facción / reputación | Grupo del mundo y puntuación de aceptación del personaje, acotada por los límites definidos en contenido. |
| Relación | Puntuación de confianza entre el personaje y un NPC. |
| Misión / etapa | Objetivo persistido de campaña y su estado: bloqueado, disponible, activo, completado o fallido. |
| Botín | Objeto concedido al resolver un encuentro, obtenido de una tabla ponderada de contenido. |
| Guardado | Instantánea local versionada de la campaña, migrada o validada antes de sustituir el estado activo. |
| Registro de eventos | Archivo JSONL local para depuración; contiene marca de tiempo y evento, rota al superar 1 MiB. |

Este glosario no afirma que las funciones omitidas de la visión general (modos, reglas o entidades) ya estén implementadas.
